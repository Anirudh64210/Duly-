Duly screens

The nine approved artboards from the design canvas. Each one opens as a working page: expandable rows, stateful checklists, switchable scenarios, confetti on completed phases.
Click any card to open that screen full size. These files render through support.js, a small standalone runtime included here, so they work from the file system with no build step. An internet connection loads Instrument Sans; without it the layout is identical but the typeface falls back.
Source of truth for Phase 4. Behaviors are written out in DESIGN-SPEC.md.

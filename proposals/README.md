# Proposals

What the skill curator proposes. Nothing here is in force.

- `lessons/`: one file for each lesson drawn from agents' reports and progress logs.
- `skills/<name>/SKILL.md`: a proposed new skill, or a proposed new text for an existing one, with a `REPLAY.md` beside it that holds the evidence.

The founder reads a proposal, and if it is accepted, copies it into `.claude/skills/` or `.claude/LESSONS/`. No agent can write there: the operating system refuses it.

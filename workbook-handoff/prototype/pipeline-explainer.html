Open-source proof-of-work tool · working draft v0.1

From the tools you already use to a sealed evidence record

No screenshots. The app reads activity you already leave in GitHub, your calendar, Slack, and your docs, groups it into work blocks, maps each block to your declared duties, and seals each day so it can't be quietly edited later. You approve everything the AI drafts.

    Plan draft

    Architecture and build order

    Runs on your machine

    • Connectors pull from GitHub, Google or Outlook Calendar, Slack, Linear or Jira, Notion or Google Docs, all read-only
    • Event store encrypted SQLite with the key in the OS keychain
    • Session builder rules that group nearby events into work blocks
    • Local AI writes the "work performed" line and suggests a duty (Apple on-device model or Ollama)
    • Sealer hashes each day and anchors it with OpenTimestamps (sends only a hash)

    Optional, your choice

    • Cloud AI with your own API key, for the monthly narrative only
    • Slack bot to post the approved daily summary
    • Encrypted backup to your own Drive, iCloud, or S3
    • Supervisor view read-only link for STEM OPT evaluations (later)
    • Parent product hook exposes the store through a clean API so the bigger product can plug in
